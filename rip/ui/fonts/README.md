# Fonts

These are the same typefaces The Library's website uses, converted from the
site's `static/fonts/*-latin.woff2` files to TrueType (`woff2_decompress`)
so Slint can embed them. They are variable fonts with the Latin subset only;
other scripts fall back to the system fonts.

| File | Typeface | Licence |
|---|---|---|
| `Fraunces-Variable-latin.ttf` | Fraunces (headings) | SIL Open Font License 1.1, `Fraunces-OFL.txt` |
| `InstrumentSans-Variable-latin.ttf` | Instrument Sans (text) | SIL Open Font License 1.1, `InstrumentSans-OFL.txt` |

Neither font has a Reserved Font Name. Monospaced text (checksums) uses the
system's monospace font.
